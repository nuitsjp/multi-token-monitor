# 契約を選んで月換算上限額の推移を見る

- 種別: 主成功
- UI確認: 要

## 開始条件
いずれかの契約の枠グループの月換算上限額が、1日以上記録されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 左メニューのUsage limitsを選ぶ | `/limits` を表示する。期間を3M、集約単位をWeekly（週次）にし、選択期間に記録がある契約をすべて選択する。左にMonthly limit（$/mo）とMultiplier（×）の折れ線グラフを上下に並べ、右に契約のタイルを並べる |
| 2 | 契約のタイルを選ぶ | その契約の選択・解除を切り替え、両グラフと凡例を更新する。1つだけ選ぶとその契約の推移、複数選ぶと契約どうしの比較になる |
| 3 | Select allを選ぶ | 全契約を選択する。全契約が選択済みのときは全契約の選択を解除する |
| 4 | 期間を選ぶ | 7D・2W・4W・3M・1Y、またはカレンダーの任意期間で、両グラフとタイルを更新する。選択は契約で保持する |
| 5 | 集約単位を選ぶ | Daily（日次）・Weekly（週次）・Monthly（月次）で両グラフを更新する。週次は月曜始まり、月次は暦月とする。各点の値は、その日・週・月の最後の記録の値とする |
| 6 | グラフの点にカーソルまたはフォーカスを合わせる | その点の期間の、選択中の各契約の月換算上限額・支払額・倍率を表示する |

## 受け入れ条件
- メニューのUsage limitsはサブメニューを持たず、By modelと同じく選ぶと `/limits` を表示する。現在のページのとき強調する。
- 上部は、Usage limitsの見出しだけとする（Hub選択は置かない。契約のタイルにHub名を示す）。
- 左にUsage over timeのカードを置き、Monthly limitとMultiplierの折れ線グラフを上下に並べる。操作欄は期間と集約単位をBy modelと同じ形式で1段に置く。既定は3M・Weeklyとする。
- 集約単位を変えても、タイルの最新値・変化率・並び順は変わらない。
- 右にPlansのカードを置き、契約ごとに1枚のタイルを並べる。タイルには、提供元のアイコン、「提供元 · プラン」、Hub名、選択期間の最新の月換算上限額、支払額、倍率、期間の最初の記録からの変化率（例: +12%）、日次推移の小さな折れ線を示す。枠グループごとの値は示さない。
- タイルの並びは、Hubの登録順、Homeの利用枠と同じ契約の順とする。
- 契約の表示名は、Homeの契約と同じく「提供元の識別子 · プラン」（例: `claude · Max 20x`）とし、タイル・凡例・ツールチップで同じ名前を使う。
- 枠グループが複数の契約（Antigravityの Gemini と Claude/GPT など）は、グループの月換算上限額を合計した1本の線と1枚のタイルで示し、倍率はその合計を支払額で割った値とする。
- 下限値の日は、両グラフでは値をそのまま線で結び、ツールチップとタイルでは「≥」を付けて示す。
- グラフのツールチップは、点の期間と、選択中の契約ごとに「月換算上限額 · 支払額 · 倍率」をこの順で見出しなしで示す。その期間に記録のない契約は「—」とする。
- 両グラフの縦軸は0から始める。タイルの小さな折れ線は、選択期間の最小値から最大値までの幅で描く。
- 契約の色は、タイルの並び順にBy modelと同じ固定パレット（8色）を割り当てる。タイル・両グラフ・凡例で同じ色を使う。
- Select all、選択数の表示（例: 3 / 4）、タイルの選択状態の見た目とキーボード操作はBy modelと同じにする。
- 選択期間に記録のない契約は、タイルに出さず、選択にも数えない。どの契約にも記録がないときは「No history for selected range.」を示す。
- 支払額が無い契約は、支払額と倍率を「N/A」とし、マウスオーバーで「No price for this plan.」を示す。
- 高さ640px以上のウィンドウで、画面全体は縦にスクロールしない。タイルの領域だけが縦にスクロールする。
- 期間・集約単位の切り替えは受け取り済みのデータで行い、APIを呼び直さない。保存の合図を受けたときは取得し直す。
