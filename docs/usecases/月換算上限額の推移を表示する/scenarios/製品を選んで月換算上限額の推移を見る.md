# 製品を選んで月換算上限額の推移を見る

- 種別: 主成功
- UI確認: 要

## 開始条件
いずれかの製品の月換算上限額が、1日以上記録されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 左メニューのUsage limitsを選ぶ | `/limits` を表示する。期間を3M、集約単位をWeekly（週次）にし、選択期間に記録がある製品をすべて選択する。左にMonthly limit（$/mo）とMultiplier（×）の折れ線グラフを上下に並べ、右に製品のタイルを並べる |
| 2 | 製品のタイルを選ぶ | その製品の選択・解除を切り替え、両グラフと凡例を更新する。1つだけ選ぶとその製品の推移、複数選ぶと製品どうしの比較になる |
| 3 | Select allを選ぶ | 全製品を選択する。全製品が選択済みのときは全製品の選択を解除する |
| 4 | 期間を選ぶ | 7D・2W・4W・3M・1Y、またはカレンダーの任意期間で、両グラフとタイルを更新する。選択は製品で保持する |
| 5 | 集約単位を選ぶ | Daily（日次）・Weekly（週次）・Monthly（月次）で両グラフを更新する。週次は月曜始まり、月次は暦月とする。各点の値は、その日・週・月の最後の記録の値とする |
| 6 | グラフの点にカーソルまたはフォーカスを合わせる | その点の期間の、選択中の各製品の月換算上限額・支払額・倍率を表示する |

## 受け入れ条件
- メニューのUsage limitsはサブメニューを持たず、By modelと同じく選ぶと `/limits` を表示する。現在のページのとき強調する。
- 上部は、Usage limitsの見出しだけとする（Hub選択は置かない。製品のタイルにHub名を示す）。
- 左にUsage over timeのカードを置き、Monthly limitとMultiplierの折れ線グラフを上下に並べる。操作欄は期間と集約単位をBy modelと同じ形式で1段に置く。既定は3M・Weeklyとする。
- 集約単位を変えても、タイルの最新値・変化率・並び順は変わらない。
- 右にPlansのカードを置き、製品ごとに1枚のタイルを並べる。タイルには、提供元のアイコン、「提供元 · プラン」、枠グループ名（グループが複数の契約だけ）、Hub名、選択期間の最新の月換算上限額、支払額、倍率、期間の最初の記録からの変化率（例: +12%）、日次推移の小さな折れ線を示す。
- タイルの並びは、Hubの登録順、Homeの利用枠と同じ契約の順、枠グループの順とする。
- 製品の色は、タイルの並び順にBy modelと同じ固定パレット（8色）を割り当てる。タイル・両グラフ・凡例で同じ色を使う。
- Select all、選択数の表示（例: 3 / 4）、タイルの選択状態の見た目とキーボード操作はBy modelと同じにする。
- 選択期間に記録のない製品は、タイルに出さず、選択にも数えない。どの製品にも記録がないときは「No history for selected range.」を示す。
- 支払額が無い製品は、支払額と倍率を「N/A」とし、マウスオーバーで「No price for this plan.」を示す。
- 高さ640px以上のウィンドウで、画面全体は縦にスクロールしない。タイルの領域だけが縦にスクロールする。
- 期間・集約単位の切り替えは受け取り済みのデータで行い、APIを呼び直さない。保存の合図を受けたときは取得し直す。
