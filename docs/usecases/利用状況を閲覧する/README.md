# 利用状況を閲覧する

## 主アクター
利用者（ブラウザーで画面を開く）

## 目的
設定した全Hubの保存済み最新利用状況を1画面で確認し、Hubごとに画面を開かずにトークン利用量・コストと利用枠の残量を把握する。

## 前提
アプリケーションが起動しており、「Hubから利用状況を同期する」で設定した全Hubがローカルに登録されている。

## 共通の受け入れ条件
- 画面とAPI応答に、HubのURLと認証トークンを含めない。
- 閲覧はローカルに保存したドメインモデルと受信状態だけを読み、Hubへ接続しない。閲覧によって保存済みの状態を変更しない。
- 画面は、開いた時点、再読み込みした時点、または同期から変更の通知を受けた時点の保存済み状態と受信状態を表示する。時間の経過だけでは取得し直さない。
