# 保存済みの最新利用状況を1画面で見る

- 種別: 主成功
- UI確認: 要

## 開始条件
利用者がブラウザーでアプリケーションの画面（`/`）を開く。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が画面を開く | 保存済みのドメインモデルを読み、次の5区画を1画面に表示する。期間は「今日」を選択した状態で表示する |
| 2 | 利用者が期間（今日・今月・累計）を切り替える | 全体の合計、Hub別、ツール・モデル別の内訳の区画を、選択した期間の値に切り替える。利用枠と端末の区画は変えない |
| 3 | 利用者が画面を再読み込みする | その時点の保存済み状態で表示し直す |

表示する区画:
1. 全体の合計: 全Hubのトークン数と推定コスト（USD）の合計。
2. Hub別: Hubごとに表示名、最終受信時刻、Hubの更新時刻、トークン数、推定コスト。状態を未受信のHubは表示名と「未受信」を示す。
3. ツール・モデル別の内訳: 全Hubを合算したツール×モデルごとのトークン数と推定コスト。トークン数の多い順に並べる。
4. 利用枠: アカウントごとに提供元、アカウントラベル、プランラベル、枠の表示名、残量（%）、次のリセット時刻。同じアカウントの同じ枠を複数Hubが報告した場合は、残量が最後に変わった時刻の新しい方だけを表示する。
5. 端末: Hub、ホスト名、OS名、最終送信時刻と、鮮度切れの端末の目印。

## 受け入れ条件
- 設定した全Hubが、未受信のHubも含めてHub別の区画に表示される。
- 画面を開いた直後は期間「今日」が選択されている。
- 合計・Hub別・内訳の値が、選択した期間の保存済み利用実績の合計と一致する。推定コストが無い実績は、コストの合計に含めず、トークン数だけを数える。
- 利用枠は、同じアカウントの同じ枠につき1行だけ表示する。
- 時刻はブラウザーのローカル時刻で表示する。
