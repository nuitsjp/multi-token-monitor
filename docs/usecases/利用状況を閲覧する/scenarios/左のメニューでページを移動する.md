# 左のメニューでページを移動する

- 種別: 拡張
- UI確認: 要

## 分岐条件
利用者が、閲覧画面の左のメニューから、Home 以外の項目を選ぶ。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が画面を開く | 画面の上端に全幅のバーを置いてサービス名「Token Monitor Analytics」をロゴと並べて示し、その下の左端に縦のメニューを表示し、右側に Home（`/`、「保存済みの最新利用状況を1画面で見る」の画面）を表示する。メニューは Home・By hub・By model・Usage limits・Devices を、この順に置く |
| 2 | 利用者が By hub または By model を選ぶ | それぞれ `/by-hub`・`/by-model` を表示する。ページの内容は未実装で、ページ名と「未実装のページです。」だけを示す |
| 3 | 利用者が Usage limits を開く | 設定した全Hubを、Hub名で並べる。未受信のHubも並べる |
| 4 | 利用者が Hub を開く | そのHubが報告した契約を「提供元 · プラン」（プランが空なら提供元だけ）で並べる。契約が無いHubは開けない行にする |
| 5 | 利用者が契約を選ぶ | `/limits/{hubId}/{契約}` を表示する。ページの内容は未実装で、「Usage limits · Hub名 · 契約名」と「未実装のページです。」だけを示す |
| 6 | 利用者が Devices を開く | 保存済みの端末を、ホスト名で並べる。同じ端末IDは1行にする |
| 7 | 利用者が端末を選ぶ | `/devices/{deviceId}` を表示する。ページの内容は未実装で、「Devices · ホスト名」と「未実装のページです。」だけを示す |

メニューの仕様:
- Usage limits と Devices の見出し、Usage limits の Hub 名の行は、開閉だけを行い、ページを移動しない。
- 現在のページに対応する項目を強調する。選択中のページを含む階層は、開いた状態にする。
- Hub・契約・端末の項目は、保存済みの状態から作る。表示中に同期で変わった状態にも追従する。
- サービス名はバーに置き、どのページでも同じ位置に示す。ページの見出しにサービス名は使わず、Home の見出しは「Home」とする。
- メニューの Home・By hub・By model・Usage limits・Devices は、名前の左にアイコンを付ける。Home の見出しと、対応する区画（By hub・By model・Usage limits・Devices）の見出しにも、同じアイコンを付ける。
- 契約の項目は、名前の左に、利用枠の契約のパネル見出しと同じ提供元（ツール）のアイコンを付ける。
- メニューは固定幅（232px）で常に左に置く。幅の狭い画面向けの切り替えは行わない。

## 受け入れ条件
- 画面の上端のバーにサービス名があり、その下の左端に縦のメニューがあり、Home・By hub・By model・Usage limits・Devices がこの順に並ぶ。
- Home を選ぶと、現在の閲覧画面がそのまま表示される。
- By hub・By model・契約・端末の各ページは、ページ名と「未実装のページです。」だけを表示する。
- Usage limits は Hub → 契約の2階層、Devices は端末の1階層で開閉でき、設定した全Hubと保存済みの全端末が並ぶ。
- 契約の項目は、利用枠の契約のパネル見出しと同じ「提供元 · プラン」と提供元のアイコンで示す。
- メニューの各項目と、Home の見出し・対応する区画の見出しに、同じアイコンが付いている。
- 現在のページの項目が強調され、そのページを含む階層は開いている。
