# 左のメニューでページを移動する

- 種別: 拡張
- UI確認: 要

## 分岐条件
利用者が、閲覧画面の左のメニューから、Home 以外の項目を選ぶ。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が画面を開く | 画面の上端に全幅のバーを置いてサービス名「Token Monitor Analytics」をロゴと並べて示し、その下の左端に縦のメニューを表示し、右側に Home（`/`、「保存済みの最新利用状況を1画面で見る」の画面）を表示する。メニューは Home・By hub・By model・By device・Usage limits を、この順に置く |
| 2 | 利用者が By hub・By model・By device のいずれかを選ぶ | それぞれ `/by-hub`・`/by-model`・`/by-device` を表示する。By hub の内容は [Hub情報を表示する](../../Hub情報を表示する/README.md)、By model の内容は [モデル情報を表示する](../../モデル情報を表示する/README.md)、By device の内容は [デバイス情報を表示する](../../デバイス情報を表示する/README.md) に従う |
| 3 | 利用者が Usage limits を選ぶ | `/limits` を表示する。内容は [月換算上限額の推移を表示する](../../月換算上限額の推移を表示する/README.md) に従う |

メニューの仕様:
- 現在のページに対応する項目を強調する。
- サービス名はバーに置き、どのページでも同じ位置に示す。ページの見出しにサービス名は使わず、Home の見出しは「Home」とする。
- メニューの Home・By hub・By model・By device・Usage limits は、名前の左にアイコンを付ける。Home の見出しと、対応する区画（By hub・By model・By device・Usage limits）の見出しにも、同じアイコンを付ける。By device のアイコンは、従来の Devices のアイコンを使う。
- メニューは固定幅（232px）で常に左に置く。幅の狭い画面向けの切り替えは行わない。

## 受け入れ条件
- 画面の上端のバーにサービス名があり、その下の左端に縦のメニューがあり、Home・By hub・By model・By device・Usage limits がこの順に並ぶ。
- Home を選ぶと、現在の閲覧画面がそのまま表示される。
- By hub は [Hub情報を表示する](../../Hub情報を表示する/README.md)、By model は [モデル情報を表示する](../../モデル情報を表示する/README.md)、By device は [デバイス情報を表示する](../../デバイス情報を表示する/README.md)、Usage limits は [月換算上限額の推移を表示する](../../月換算上限額の推移を表示する/README.md) に従って表示する。
- メニューの項目はどれもサブメニューを持たず、選ぶとそのページへ移動する。
- メニューの各項目と、Home の見出し・対応する区画の見出しに、同じアイコンが付いている。
- 現在のページの項目が強調される。
