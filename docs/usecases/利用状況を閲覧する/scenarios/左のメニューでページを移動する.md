# 左のメニューでページを移動する

- 種別: 拡張
- UI確認: 要

## 分岐条件
利用者が、閲覧画面の左のメニューから、Home 以外の項目を選ぶ。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が画面を開く | 画面の上端に全幅のバーを置いてサービス名「Token Monitor Analytics」をロゴと並べて示し、その下の左端に縦のメニューを表示し、右側に Home（`/`、「保存済みの最新利用状況を1画面で見る」の画面）を表示する。メニューは Home・By hub・By model・Usage limits・Devices を、この順に置く |
| 2 | 利用者が By hub または By model を選ぶ | それぞれ `/by-hub`・`/by-model` を表示する。By hub の内容は [Hub情報を表示する](../../Hub情報を表示する/README.md)、By model の内容は [モデル情報を表示する](../../モデル情報を表示する/README.md) に従う |
| 3 | 利用者が Usage limits を選ぶ | `/limits` を表示する。内容は [月換算上限額の推移を表示する](../../月換算上限額の推移を表示する/README.md) に従う |
| 4 | 利用者が Devices を開く | 保存済みの端末を、ホスト名で並べる。同じ端末IDは1行にする |
| 5 | 利用者が端末を選ぶ | `/devices/{deviceId}` を表示する。ページの内容は未実装で、「Devices · ホスト名」と「未実装のページです。」だけを示す |

メニューの仕様:
- Devices の見出しは、開閉だけを行い、ページを移動しない。
- 現在のページに対応する項目を強調する。選択中のページを含む階層は、開いた状態にする。
- 端末の項目は、保存済みの状態から作る。表示中に同期で変わった状態にも追従する。
- サービス名はバーに置き、どのページでも同じ位置に示す。ページの見出しにサービス名は使わず、Home の見出しは「Home」とする。
- メニューの Home・By hub・By model・Usage limits・Devices は、名前の左にアイコンを付ける。Home の見出しと、対応する区画（By hub・By model・Usage limits・Devices）の見出しにも、同じアイコンを付ける。
- メニューは固定幅（232px）で常に左に置く。幅の狭い画面向けの切り替えは行わない。

## 受け入れ条件
- 画面の上端のバーにサービス名があり、その下の左端に縦のメニューがあり、Home・By hub・By model・Usage limits・Devices がこの順に並ぶ。
- Home を選ぶと、現在の閲覧画面がそのまま表示される。
- By hub は [Hub情報を表示する](../../Hub情報を表示する/README.md)、By model は [モデル情報を表示する](../../モデル情報を表示する/README.md)、Usage limits は [月換算上限額の推移を表示する](../../月換算上限額の推移を表示する/README.md) に従って表示する。端末の各ページは、ページ名と「未実装のページです。」だけを表示する。
- Usage limits はサブメニューを持たない1項目で、選ぶと `/limits` へ移動する。Devices は端末の1階層で開閉でき、保存済みの全端末が並ぶ。
- メニューの各項目と、Home の見出し・対応する区画の見出しに、同じアイコンが付いている。
- 現在のページの項目が強調され、そのページを含む階層は開いている。
