# 選択したHubの利用状況を見る

- 種別: 主成功
- UI確認: 要

## 開始条件
対象Hubの利用状況が保存されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 左メニューのBy hubを選ぶ | 登録順で最初のHubを選び、期間2W・集約単位Daily（日次）で表示する |
| 2 | Hubの切り替えを選ぶ | 選択したHubの接続状態・最終受信・期間合計Tokens／Cost・グラフ・Devicesを表示する |
| 3 | 期間を選ぶ | 7D・2W・4W・3M・1Yまたはカレンダーの任意期間で、全区画を同じ期間に更新する |
| 4 | 集約単位を選ぶ | Daily（日次）・Weekly（週次）・Monthly（月次）で両グラフを更新する。週次は月曜始まり、月次は暦月とする |
| 5 | グラフの棒にカーソルまたはフォーカスを合わせる | 対象期間のモデル別TokensまたはCostを表示する |
| 6 | モデルの凡例を選ぶ | 両グラフの対応するモデルを表示・非表示にする |
| 7 | Devicesのデバイス名を選ぶ | 既存のデバイス詳細ページへ移動する |

## 受け入れ条件
- 上部はBy hub、Tokens、Cost、Hub切り替え、接続状態・Last receivedの順に配置し、接続状態とLast receivedは右寄せにする。
- By hubのタイトルとTokens・Costは、視覚上の上下中央を揃える。
- 期間ボタンのサイズと余白は、HomeのTodayボタンに揃える。既定期間は2Wとする。
- グラフの操作欄は1段とし、期間・集約単位を共用する。
- TokensとCostのモデル別積み上げ棒グラフを上下に並べる。
- 選択Hub・選択期間のトークン合計で上位5モデルを選び、残りをOtherにまとめる。同名モデルはツール間で合算する。
- 両グラフは同じモデル・色・積み上げ順を使う。
- Devicesをグラフの右に配置し、コストの大きい順に並べる。
- デバイス名の右にOS、状態の右にLast seenを置く。
- TokensとCostを別色の2本のバーで並べ、数値・構成比の列をデバイス間で揃える。
- バーは、それぞれ選択HubのTokens合計・Cost合計に占める割合を示す。
- 集約単位を変えても、上部とDevicesの期間合計は変わらない。
- 利用枠、独立したコスト内訳パネルは表示しない。
- デバイス詳細ページ自体の新規実装は、このユースケースの対象外とする。
