# 表示中に同期された状態を反映する

- 種別: 拡張
- UI確認: 要

## 分岐条件
表示中に同期の保存確定通知または鮮度更新を受ける。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | By hubを表示している | 保存確定後に最新の閲覧データを取得し、選択中のHub・期間・集約単位を保って更新する |
| 2 | 鮮度更新を受ける | 接続・受信時刻・デバイスの鮮度を更新し、利用量は変更しない |
| 3 | Hubの受信が止まる | 再接続中と最終受信時刻を表示し、保存済みデータを維持する |

## 受け入れ条件
- 他のHubの受信停止で表示や同期を止めない。
- 未保存の状態を表示しない。
- 通信失敗時に静的サンプルへ切り替えない。
