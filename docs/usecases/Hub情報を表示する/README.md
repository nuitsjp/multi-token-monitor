# Hub情報を表示する

## 主アクター
利用者。

## 目的
Hubを切り替えながら、モデル別の利用量・推定コストの変遷と、デバイス別の利用状況・鮮度を確認する。

## 前提
アプリケーションが起動し、接続設定にあるHubが登録されている。

## 共通の受け入れ条件
- 動作合意済みの画面を基準とし、Homeの文字サイズ・余白・バーの太さを使う。
- 配色は03を使用する。
- 画面の表示はすべて英語とし、トークン数は「Tokens」、推定コストは「Cost」と表記する。
- トークン数は、上部の期間合計・Devices・グラフの軸・ツールチップのすべてで整数をカンマ区切りで表示し、K・Mで省略しない。
- 閲覧は保存済みデータを読み、Hubへの接続やデータの書き換えを行わない。
- HubのURL・認証トークンを画面・閲覧APIに含めない。
- 日付はデバイスが報告した日付を使う。当日の履歴と最新の当日利用量は重複加算しない。
- 保存済みの日次明細の有無から表示値を求める。選択期間に明細が無い場合の数値は「—」とし、独立した履歴取得可否フラグは設けない。未取得の利用量や不明なコストを、ゼロとして表示しない。
