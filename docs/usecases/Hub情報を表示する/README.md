# Hub情報を表示する

## 主アクター
利用者。

## 目的
Hubを切り替えながら、モデル別の利用量・推定コストの変遷と、デバイス別の利用状況・鮮度を確認する。

## 前提
アプリケーションが起動し、接続設定にあるHubが登録されている。

## 共通の受け入れ条件
- 承認済みの静的HTMLを画面の基準とし、Homeの文字サイズ・余白・バーの太さを使う。
- 配色は03を使用する。
- 閲覧は保存済みデータを読み、Hubへの接続やデータの書き換えを行わない。
- HubのURL・認証トークンを画面・閲覧APIに含めない。
- 日付はデバイスが報告した日付を使う。当日の履歴と最新の当日利用量は重複加算しない。
- 未取得の利用量や不明なコストを、ゼロとして表示しない。
