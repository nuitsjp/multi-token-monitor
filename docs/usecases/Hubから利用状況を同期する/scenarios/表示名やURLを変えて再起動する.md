# 表示名やURLを変えて再起動する

- 種別: 拡張
- UI確認: 不要

## 分岐条件
主成功シナリオで利用者がアプリケーションを起動するとき、以前の起動で登録したHubについて、同じIDのまま接続設定の表示名またはURLが変わっている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が、HubのIDを変えずに表示名またはURLを書き換えてアプリケーションを起動する | 主成功シナリオと同じく接続設定を検証し、同じIDのHubの表示名を新しい値に更新する。保存済みの最新状態と受信時刻は保持し、設定のURLへ受信を開始する |
| 2 | 新しいURLのHubが接続時の全体状態（snapshot）を送る | 保存済みの最新状態を全体置換し、受信時刻とともに保存する。保存の確定後、閲覧側へ変更を通知する |

## 受け入れ条件
- 起動後、Hubから受信する前でも、同じIDのHubを新しい表示名で読み取れる。
- URLを変えた場合は、新しいURLだけに接続し、以前のURLには接続しない。新しいURLから最初の全体状態を受けるまでは、前回保存した最新状態と受信時刻を保持する。
- 新しいURLから受けた最初の全体状態で最新状態を置き換え、前回保存した利用量に加算しない。
- IDを変えた場合は、元のIDのHubを設定から外し、新しいIDのHubを追加したものとして扱う。
