# 接続設定が不正なため起動しない

- 種別: 拡張
- UI確認: 不要

## 分岐条件
主成功シナリオで利用者がアプリケーションを起動するとき、接続設定ファイルの検証で次のいずれかに該当した。

| 条件 | 標準エラーに出力する理由 |
| --- | --- |
| `.env` の `HUB_CONFIG_PATH` が未設定 | HUB_CONFIG_PATHにHub接続設定ファイルを指定してください。 |
| ファイルがない、または読み込めない | Hub接続設定ファイルを読み込めません。 |
| JSONが不正、Hubが0件、必須項目（ID・表示名・URL・認証トークン）の欠落・空欄、認証トークンに制御文字を含む | Hub接続設定ファイルの形式が不正です。 |
| 空白を除いたHub IDが重複している | Hub接続設定ファイルのHub IDが重複しています。 |
| URLが `http(s)://ホスト[:ポート]` の形式でない（パス・クエリ・フラグメント・ユーザー情報を含む場合を含む） | Hub接続設定ファイルのURLが不正です。 |

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が、不正な接続設定でアプリケーションを起動する | 接続設定の検証で該当した条件の理由を標準エラーに1行出力し、終了コード1で終了する。DBを開かず、Hubへ接続せず、Webサーバーも起動しない |

## 受け入れ条件
- 分岐条件の各条件で、対応する理由を標準エラーに出力し、終了コード1で終了する。
- 起動前のDBの内容は変わらない。保存済みの状態も、設定から外れたHubの削除も行われない。
- Hubへ接続せず、Webサーバーは待ち受けない。
- 出力にURLと認証トークンを含めない。
