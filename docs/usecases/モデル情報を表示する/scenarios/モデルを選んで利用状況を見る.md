# モデルを選んで利用状況を見る

- 種別: 主成功
- UI確認: 要

## 開始条件
いずれかのHubの利用状況が保存されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 左メニューのBy modelを選ぶ | Hub選択をAll、期間を2W、集約単位をDaily（日次）にする。選択期間に明細があるモデルを右のModelsに利用率の降順で並べる。コストの大きい順の上位5モデルを選択状態にし、そのグラフ（未選択のモデルはOtherに合算）と、全モデルの期間合計を表示する |
| 2 | 右上のHub選択でAllまたは個別Hubを選ぶ | Allでは全Hub、個別HubではそのHubだけを集計し、期間合計・グラフ・凡例・Modelsを更新する |
| 3 | モデルのタイルを選ぶ | そのモデルの選択・解除を切り替え、グラフと凡例を更新する |
| 4 | Select allを選ぶ | 表示対象の全モデルを選択する。全モデルが選択済みのときは全モデルの選択を解除する。グラフと凡例を更新する |
| 5 | 期間を選ぶ | 7D・2W・4W・3M・1Yまたはカレンダーの任意期間で、全区画を同じ期間に更新する |
| 6 | 集約単位を選ぶ | Daily（日次）・Weekly（週次）・Monthly（月次）で両グラフを更新する。週次は月曜始まり、月次は暦月とする |
| 7 | グラフの棒にカーソルまたはフォーカスを合わせる | 対象期間の、選択中のモデルとOtherのTokensまたはCostを表示する |

## 受け入れ条件
- 上部はBy model、Tokens、Cost、Hub選択の順に配置し、Hub選択は右上に置く。Hub選択には、By hubと同じ形式のコントロールを使い、Allを先頭、その後に登録順で個別Hubを並べる。初期選択はAllとする。
- TokensとCostは、モデルの選択にかかわらず、選択対象のHub・選択期間の全モデルの合計とする。接続状態・Last receivedは表示しない。
- 左にUsage over timeのカード、右にModelsのカードを置く。TokensとCostのモデル別積み上げ棒グラフを上下に並べ、操作欄（期間・集約単位）は1段とする。既定期間は2Wとする。
- 高さ640px以上のウィンドウで、画面全体は縦にスクロールしない。高さはウィンドウに収め、グラフは残りの高さに合わせて伸縮する。グラフの操作欄は、枠の幅が足りないとき折り返す。内容の幅が640pxを下回るときは、ページ全体を横にスクロールさせる。
- Modelsの見出しの下に、三状態の「Select all」チェックボックスと選択数（例: 5 / 9）を置く。全選択のとき✔、一部選択のとき中間表示、選択なしのとき空欄とし、クリックすると全選択（全選択済みのときは全解除）にする。各タイルの左端にも、選択状態を示すチェックを表示する。見出しは固定し、タイルの領域だけが縦に独立してスクロールする。
- タイルは利用率の降順に並べる。利用率は、選択対象のHub・選択期間の全モデルのトークン合計に占める各モデルの割合とする。並び順は丸める前の値で比較し、同順位は名前順とする。トークン合計がゼロの場合の利用率は0%とする。
- タイルにはモデル名、トークンの構成比、Cost、Tokens、選択期間の日次推移の折れ線を表示する。
- 初期選択はコストの大きい順の上位5モデルとする。初期選択の判定では、コスト不明のモデルは最後に置き、同順位は名前順とする。
- タイルは選択中を通常の濃さと枠付き、未選択を薄く表示する。マウスのほか、キーボード（EnterまたはSpace）でも切り替えられ、選択状態を `aria-pressed` で示す。
- モデルの色は、タイルの並び順に固定のパレット（8色）を順に割り当て、超えた分は先頭から繰り返す。タイル・グラフ・凡例で同じ色を使い、両グラフは同じ積み上げ順（タイルの並び順を下から上）とする。
- 選択中のモデルはモデルごとの色で積み上げ、選択していないモデルは合算して灰色のOtherとして最上段に積む。凡例には、選択中のモデルと、未選択のモデルがあるときのOtherを表示し、操作はタイルで行う。選択が0件のときはOtherだけを表示し、棒の合計は選択によらず表示対象の全モデルの値とする。
- Hub・期間・集約単位を変えても選択は、モデル名で保持する。選択対象のHub・選択期間に明細が無いモデルはタイルに出さず、選択状態にも数えない。
- Hubを切り替えても期間・集約単位は保持する。Hub・期間を変えた場合、変更後の利用率でタイルを並べ直す。
- 選択対象のHub・選択期間にどのモデルの明細も無いとき、Modelsに「No history for selected range.」を表示する。
- 集約単位を変えても、上部とタイルの期間合計・利用率・並び順は変わらない。
- Hubごと・デバイスごとの内訳、Hubの接続状態、利用枠は表示しない。
- Hubの切り替えは受け取り済みのデータで行い、APIを呼び直さない。
