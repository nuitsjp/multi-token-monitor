# モデル情報を表示する

## 主アクター
利用者。

## 目的
全Hubを合算したモデル別の利用量・推定コストの変遷と、モデル間の構成を、モデルを選びながら確認する。

## 前提
アプリケーションが起動し、接続設定にあるHubが登録されている。

## 共通の受け入れ条件
- 動作合意済みの画面を基準とし、By hubと同じ文字サイズ・余白・配色を使う。トークン数と推定コストの数値更新は [UCP-2の共通処理](../../design/UCP-2.md#共通の処理) に従う。
- 画面の表示はすべて英語とし、トークン数は「Tokens」、推定コストは「Cost」と表記する。
- トークン数は、上部の期間合計・モデルのタイル・グラフの軸・ツールチップのすべてで整数をカンマ区切りで表示し、K・Mで省略しない。
- 閲覧は保存済みデータを読み、Hubへの接続やデータの書き換えを行わない。
- HubのURL・認証トークンを画面・閲覧APIに含めない。
- 集計は全Hubの保存済み日次明細を合算し、同名モデルはツール・Hub・デバイスをまたいで合算する。日付はデバイスが報告した日付を使い、当日の履歴と最新の当日利用量は重複加算しない。
- 選択期間に明細が無い場合の数値は「—」とし、未取得の利用量や不明なコストをゼロとして表示しない。
