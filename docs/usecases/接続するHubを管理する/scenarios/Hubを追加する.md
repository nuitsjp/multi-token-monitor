# Hubを追加する

- 種別: 主成功
- UI確認: 要

## 開始条件
利用者が、閲覧画面の左のメニューから Settings を選ぶ。登録済みのHubは0件でも1件以上でもよい。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が左のメニューの Settings を選ぶ | `/settings` を表示する。見出しは「Settings」とし、「Hubs」の区画に、登録済みのHubを登録順に、表示名・URL・受信状態（Connected・Not received・Reconnecting）で一覧する。「Hubs」の見出しの右端に追加のアイコンボタン（＋、名称「Add hub」）を置き、追加フォームは通常表示しない。0件のときは一覧の代わりに「No hubs registered.」を示す。認証トークンは一覧に表示しない |
| 2 | 利用者が追加のアイコンボタンを押し、開いたポップアップ（見出し「Add hub」）で Name・URL・Token を入力して Add hub を押す | ポップアップに空のフォームを表示する。Add hub を押すと、入力を [共通の受け入れ条件](../README.md#共通の受け入れ条件) の検証にかけ、満たせば同じ条件の接続の確認を行う。応答を受ければ、IDを採番してHubをDBへ保存し、保存の確定後に閲覧側へ変更を通知する。受信状態は、最初の全体状態を受けるまで Not received とする。ポップアップを閉じ、追加したHubを一覧の末尾に示す |
| 3 | （システムが続ける）追加したHubが接続時の全体状態（snapshot）を送る | [Hubから利用状況を同期する](../../Hubから利用状況を同期する/README.md) の主成功シナリオに従って保存する。アプリケーションの再起動なしに、追加したHubへの受信が開始されている。一覧の受信状態は Connected になり、Home・By hub・By model・By device・Usage limits に追加したHubの利用状況が反映される |

画面の規則:
- Settings の見出しの左に、メニューの Settings と同じ歯車のアイコンを付ける。
- 追加フォームは、画面の中央に重ねて表示するポップアップに置く。×ボタンまたは外側の操作で、保存せずに閉じる。開くたびに空のフォームから始める。
- 文字サイズ・余白・配色は Home と By hub の画面に合わせる。
- 入力中の検証は行わず、Add hub を押したときに検証する。ポップアップを開いたまま、該当した項目のそばにメッセージを示し、入力値は残す。
- 保存の前に接続の確認を行い、接続できない入力は保存しない。保存後に接続が切れた場合は、一覧の受信状態が Reconnecting になる。

## 受け入れ条件
- 左のメニューの一番下に Settings があり、選ぶと `/settings` を表示する。登録済みのHubは登録順に、表示名・URL・受信状態で並ぶ。追加フォームは通常表示されず、認証トークンはどこにも表示されない。
- 追加のアイコンボタンを押すと、Name・URL・Token と Add hub ボタンを持つポップアップが開く。閉じて開き直すと、フォームは空である。
- 0件のとき、一覧の代わりに「No hubs registered.」と追加のアイコンボタンが表示される。
- 表示名・URL・認証トークンを満たし、接続の確認で応答を受けた入力でAdd hubを押すと、HubがDBに保存され、ポップアップが閉じて、一覧の末尾に加わる。IDは入力せずに採番され、同じ表示名・同じURLのHubを複数追加できる。
- 追加したHubは、アプリケーションを再起動せずに、入力したURLへ入力した認証トークンで受信を開始する。最初の全体状態を受けるまで Not received、受けた後は Connected、保存後に接続が切れている間は Reconnecting と表示される。
- 追加したHubの利用状況が、最初の全体状態を受けた後、他のページを開き直さずに反映される。
- 検証を満たす入力でも、接続の確認が失敗すると、共通の受け入れ条件のメッセージがTokenの項目のそばに表示され、ポップアップは開いたまま、DBへの保存も受信の開始も行われず、入力値が残る。
- 検証に該当する入力では、接続の確認を行わず、対応するメッセージがポップアップ内の項目のそばに表示され、ポップアップは開いたまま、DBへの保存も受信の開始も行われず、入力値が残る。複数の項目が該当すれば、それぞれのメッセージが表示される。
- 追加したHubへの接続の失敗は、他のHubの受信とWebサーバーを止めない。
- 認証トークンは、DBの値を除き、画面・閲覧用API・ログ・通知に現れない。
