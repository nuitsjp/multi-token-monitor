# 接続するHubを管理する

## 主アクター
利用者。

## 目的
利用状況を取得するHubを、画面の設定から追加・変更・削除し、設定ファイルを編集せず、アプリケーションを再起動せずに、受信の対象へ反映する。Hubは複数登録できる。

## 前提
アプリケーションが起動している。登録済みのHubが0件でもよい。

## 共通の受け入れ条件
- 登録するHubは、表示名・URL・認証トークンで構成する。IDはアプリケーションが採番し、利用者は入力しない。表示名は重複してよい。
- Hubの登録情報の正本はDBとする。接続設定ファイルと環境変数 `HUB_CONFIG_PATH` は使わない。
- 認証トークンは画面・閲覧用API・ログ・通知に含めない。登録後に画面で読み返せず、変更するときは入れ直し、入れ直さなければ登録済みの値を保つ。URLは設定画面にだけ表示し、他の画面・閲覧用API・ログ・通知には含めない。
- 入力の検証は次の条件で行い、該当した項目のそばに英語のメッセージを示す。1つでも該当したら保存せず、受信も変えない。

| 項目 | 条件 | メッセージ |
| --- | --- | --- |
| 表示名 | 空白を除いて空 | Enter a name. |
| URL | `http(s)://ホスト[:ポート]` の形式でない（パス・クエリ・フラグメント・ユーザー情報を含む場合を含む） | Enter a URL like http(s)://host[:port]. |
| 認証トークン | 空（変更では、登録済みの認証トークンがある場合は空を許す）、または制御文字を含む | Enter a valid token. |

- 登録・変更・削除は、保存の確定後に受信の対象へ反映し、閲覧側へ変更を通知する。あるHubの受信の失敗は、他のHubの受信とWebサーバーに波及しない。
- 画面の表示はすべて英語とする。
