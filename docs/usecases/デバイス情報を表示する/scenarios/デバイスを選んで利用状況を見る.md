# デバイスを選んで利用状況を見る

- 種別: 主成功
- UI確認: 要

## 開始条件
いずれかのHubの利用状況が保存されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 左メニューのBy deviceを選ぶ | Hub選択をAll、期間を2W、集約単位をDaily（日次）、DevicesのソートをTokensにする。選択期間に明細があるデバイスをTokensの降順で並べ、表示先頭5デバイスを選択する。そのグラフ（未選択のデバイスはOtherに合算）と、全デバイスの期間合計を表示する |
| 2 | 右上のHub選択でAllまたは個別Hubを選ぶ | Allでは全Hub、個別HubではそのHubだけを集計し、期間合計・グラフ・凡例・Devicesを更新する。現在のソートで表示先頭5デバイスを選び直す |
| 3 | Devices見出しのTokensまたはCostを選ぶ | 選択した項目の降順でタイルを並べ直し、表示先頭5デバイスを選び直す。グラフと凡例を更新する |
| 4 | デバイスのタイルを選ぶ | そのデバイスの選択・解除を切り替え、グラフと凡例を更新する |
| 5 | Select allを選ぶ | 表示対象の全デバイスを選択する。全デバイスが選択済みのときは全デバイスの選択を解除する。グラフと凡例を更新する |
| 6 | 期間を選ぶ | 7D・2W・4W・3M・1Yまたはカレンダーの任意期間で、全区画を同じ期間に更新する |
| 7 | 集約単位を選ぶ | By modelと同じDaily（日次）・Weekly（週次）・Monthly（月次）の区切りで両グラフを更新する |
| 8 | グラフの棒にカーソルまたはフォーカスを合わせる | 対象期間の、選択中のデバイスとOtherのTokensまたはCostを表示する |
| 9 | 個別Hub名横の状態アイコンにカーソルを合わせる | Hubの状態をTooltipで表示する |

## 受け入れ条件
- 上部はBy device、Tokens、Cost、Hub選択の順に配置し、Hub選択は右上に置く。Hub選択にはBy modelと同じコントロールを使い、Allを先頭、その後に登録順で個別Hubを並べる。初期選択はAllとする。
- 個別Hub名横の状態アイコン（色・Tooltipの文言・Allには表示しないこと・時刻を表示しないこと）は、[By model](../../モデル情報を表示する/scenarios/モデルを選んで利用状況を見る.md) と同じとする。
- TokensとCostは、デバイスの選択にかかわらず、選択対象のHub・選択期間の全デバイスの合計とする。
- 左にUsage over timeのカード、右にDevicesのカードを置く。TokensとCostのデバイス別積み上げ棒グラフを上下に並べ、操作欄（期間・集約単位）は1段とする。既定期間は2Wとする。
- 高さ640px以上のウィンドウで縦にスクロールしないこと、グラフの伸縮、操作欄の折り返し、内容の幅が640pxを下回るときの横スクロールは、By modelと同じとする。
- Devicesの見出しの下に、三状態の「Select all」チェックボックスと選択数（例: 5 / 9）を置く。全選択のとき✔、一部選択のとき中間表示、選択なしのとき空欄とし、クリックすると全選択（全選択済みのときは全解除）にする。各タイルの左端にも、選択状態を示すチェックを表示する。見出しは固定し、タイルの領域だけが縦に独立してスクロールする。
- Devicesの見出しにTokens／Costのソート切り替えを置き、初期選択はTokensとする。タイルは選択した項目の降順に並べ、同順位はホスト名順、さらに同じ場合はデバイスID順とする。Costが不明なデバイスは最後に置く。比較には丸める前の値を使う。
- デバイスはデバイスIDで識別し、タイル・凡例・ツールチップではホスト名で示す。同じデバイスIDが複数のHubにあるときは1つのデバイスとして合算し、ホスト名とOSは登録順で最初のHubの値を使う。
- タイルのトークン構成比は、選択対象のHub・選択期間の全デバイスのトークン合計に占める各デバイスの割合とする。トークン合計がゼロの場合は0%とする。
- タイルにはホスト名、OS、トークンの構成比、Cost、Tokens、選択期間の日次推移の折れ線を表示する。
- 初回表示・Hub変更・ソート変更のたびに、現在の表示先頭5デバイスを選び直す。表示対象が5件未満なら全件、0件なら選択なしとする。その後はタイルで手動選択できる。
- タイルの選択中・未選択の表示、マウスとキーボード（EnterまたはSpace）での切り替え、`aria-pressed` による選択状態の提示は、By modelのタイルと同じとする。
- デバイスの色は、タイルの並び順に固定のパレット（8色）を順に割り当て、超えた分は先頭から繰り返す。タイル・グラフ・凡例で同じ色を使い、両グラフは同じ積み上げ順（タイルの並び順を下から上）とする。
- 選択中のデバイスはデバイスごとの色で積み上げ、選択していないデバイスは合算して灰色のOtherとして最上段に積む。凡例には、選択中のデバイスと、未選択のデバイスがあるときのOtherを表示し、操作はタイルで行う。選択が0件のときはOtherだけを表示し、棒の合計は選択によらず表示対象の全デバイスの値とする。
- 期間・集約単位を変えても選択は、デバイスIDで保持する。選択対象のHub・選択期間に明細が無いデバイスはタイルに出さず、選択状態にも数えない。
- Hub・期間・集約単位・ソートの相互の保持と、Hub・期間・ソートの変更後に選択項目の値でタイルを並べ直すことは、By modelと同じとする。
- 選択対象のHub・選択期間にどのデバイスの明細も無いとき、Devicesに「No history for selected range.」を表示する。
- 集約単位を変えても、上部とタイルの期間合計・利用率・並び順は変わらない。
- モデルごとの内訳、デバイスの鮮度（Live／Stale・Last seen）、利用枠は表示しない。
- Hub・ソートの切り替えは受け取り済みのデータで行い、APIを呼び直さない。
