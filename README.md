# Token Monitor Analytics

設定した複数の Token Monitor Hub から最新の利用状況を受信してローカルの SQLite へ保存し、ブラウザーのダッシュボードで閲覧するローカルアプリです。React・ASP.NET Core・SQLite で構成します。

起動と検証の手順は [プロジェクト定義](docs/project.md#commands) を参照してください。
