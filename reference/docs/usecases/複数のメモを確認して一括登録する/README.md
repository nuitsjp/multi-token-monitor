# 複数のメモを確認して一括登録する

## 主アクター

利用者

## 目的

複数のメモを確認したうえでまとめて保存する（[プロジェクトの目的と範囲](../../project.md) との対応）。

## 前提

利用者として識別されている。件数上限は [プロジェクト定義の制約](../../project.md#constraints) に従う。

## 共通の受け入れ条件

プレビュー段階で DB を更新しないこと。画面遷移時に入力の下書きを維持すること。
