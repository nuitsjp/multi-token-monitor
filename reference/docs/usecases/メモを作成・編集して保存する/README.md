# メモを作成・編集して保存する

## 主アクター

利用者

## 目的

自身のメモを保存し、後から参照・編集する（[プロジェクトの目的と範囲](../../project.md) との対応）。

## 前提

利用者として識別されている（参照実装ではローカル用のユーザー選択）。

## 共通の受け入れ条件

保存・削除が成功した場合は、画面表示だけでなく SQLite への変更が確定し、再起動後も保持されること。別タブへは確定後の通知で一覧が追従すること。
